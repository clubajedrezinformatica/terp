Un programa escrito en C está compuesto por varias partes que incluyen las siguientes:

Directivas de preprocesador: Estas son líneas de código que comienzan con "#" y se utilizan para incluir archivos de encabezado (header files), definir macros y otras configuraciones de compilación.

Función principal (main): Toda aplicación escrita en C debe tener una función principal que se ejecuta automáticamente al iniciar el programa. La función principal se define con el siguiente encabezado: int main(void){}

Declaraciones de variables: Las variables se declaran al principio del programa y se utilizan para almacenar valores. La declaración de una variable en C incluye su tipo de datos y su nombre, por ejemplo: int numero; char letra; float precio; 

Instrucciones: Las instrucciones son las líneas de código que realizan operaciones en el programa, como asignar valores a variables, realizar operaciones matemáticas, llamar a funciones, entre otras.

Funciones: Las funciones son bloques de código que realizan una tarea específica. En C, se pueden crear funciones personalizadas, además de las funciones predefinidas que se incluyen en las bibliotecas estándar de C.

Comentarios: Los comentarios son líneas de código que no se ejecutan, pero que se utilizan para agregar notas y explicaciones al programa. En C, se pueden escribir comentarios de dos maneras: //(una sola línea) /* */(línea múltiple) 

Bibliotecas: Las bibliotecas son colecciones de funciones predefinidas que se pueden utilizar en un programa. En C, se pueden incluir bibliotecas estándar, como stdio.h y stdlib.h, para acceder a funciones útiles como printf() y malloc().

En resumen, un programa escrito en C tiene una estructura definida que incluye directivas de preprocesador, función principal, declaraciones de variables, instrucciones, funciones, comentarios y bibliotecas. La forma en que se organizan estas partes dependerá de la aplicación específica que se esté creando.

SOBRE EL ANIDAMIENTO DE FUNCIONES 
En C no existe el anidamiento de funciones de forma directa. Esto significa que no se pueden definir funciones dentro de otras funciones como se hace en otros lenguajes de programación como Python o JavaScript.

EJERCICIO 10 - Manejo de expresiones 

El lenguaje C ofrece un manejo de expresiones muy poderoso y flexible, permitiendo al programador realizar operaciones matemáticas, lógicas y de comparación de manera sencilla y eficiente.

Las expresiones en C pueden incluir:

Operandos: Los operandos pueden ser variables, constantes o valores resultantes de otras expresiones.
Operadores: Los operadores pueden ser aritméticos, lógicos, de comparación, de asignación, entre otros. Cada operador tiene un nivel de precedencia y asociatividad que define el orden en que se evalúan las expresiones.
La evaluación de las expresiones en C se realiza de acuerdo con las reglas de precedencia y asociatividad de los operadores. En general, los operadores aritméticos tienen mayor precedencia que los operadores de comparación, y éstos a su vez tienen mayor precedencia que los operadores lógicos.

Además, C utiliza reglas de conversión de tipos (llamado "coerción de tipos") para asegurar que los operandos de las expresiones se puedan combinar de manera compatible con los operadores. Por ejemplo, si se intenta sumar un número entero con un número flotante, C realizará automáticamente una conversión implícita del número entero al tipo de dato flotante antes de realizar la operación.

En general, el manejo de expresiones en C es muy potente y flexible, permitiendo al programador realizar cálculos complejos de manera sencilla y eficiente. Sin embargo, es importante tener en cuenta que el manejo de expresiones en C puede ser propenso a errores si no se tiene cuidado al combinar diferentes tipos de datos o al utilizar operadores con diferentes niveles de precedencia.
Sin embargo, es posible crear funciones dentro de bloques de código utilizando el concepto de funciones anónimas o funciones lambda. Esto se logra utilizando punteros a funciones y definiendo la función dentro del bloque de código donde se desea utilizar. Aunque esto no es exactamente lo mismo que anidar funciones, permite crear funciones dentro de bloques de código y mejorar la modularidad del programa.

CARACTERÍSTICAS IMPORTANTES

a)Python es un lenguaje de programación de alto nivel que se destaca por su simplicidad, flexibilidad, legibilidad y eficiencia en el desarrollo de aplicaciones. Algunas de las características más importantes de Python son las siguientes:
Fácil de aprender: Python es un lenguaje de programación muy fácil de aprender y usar, lo que lo convierte en una excelente opción para principiantes en la programación. La sintaxis simple y clara de Python, junto con su amplia biblioteca estándar, hace que sea fácil para los programadores escribir código de manera rápida y efectiva.
Multiplataforma: Python se puede ejecutar en una amplia variedad de plataformas, incluyendo Windows, Linux, macOS y otros sistemas operativos.
Interpretado: Python es un lenguaje de programación interpretado, lo que significa que el código fuente se ejecuta directamente en la máquina en lugar de compilarlo antes de su ejecución. Esto permite una mayor flexibilidad en el proceso de desarrollo, ya que los programadores pueden escribir, probar y modificar el código en tiempo real.
Tipado dinámico: Python es un lenguaje de programación de tipado dinámico, lo que significa que el tipo de una variable se determina en tiempo de ejecución en lugar de ser declarado en el momento de la compilación. Esto permite una mayor flexibilidad en el proceso de desarrollo, ya que los programadores pueden trabajar con diferentes tipos de datos sin necesidad de declararlos de antemano.
Orientado a objetos: Python es un lenguaje de programación orientado a objetos (OOP), lo que significa que las clases y los objetos son fundamentales en la construcción de programas. La programación orientada a objetos permite la creación de código modular y reutilizable, lo que facilita el mantenimiento y la extensión del código.
Amplia biblioteca estándar: Python tiene una amplia biblioteca estándar que proporciona módulos y herramientas para una variedad de tareas, desde la manipulación de cadenas y archivos hasta la creación de interfaces gráficas de usuario y la conexión a bases de datos.
En resumen, Python es un lenguaje de programación de alto nivel y fácil de aprender, multiplataforma, interpretado, de tipado dinámico, orientado a objetos y con una amplia biblioteca estándar. Estas características lo convierten en una opción popular para una amplia gama de aplicaciones de programación.
